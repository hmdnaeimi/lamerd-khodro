# نصب وردپرس لامرد خودرو (نسخه اجرایی کامل)

این پوشه یک نصب کامل و کارکرده وردپرس است که سایت لامرد خودرو در آن بالا آمده: هسته وردپرس ۷.۱.۴، پوسته «لامرد خودرو»، دو افزونه `lamerd-khodro-core` و `lamerd-khodro-price-engine`، و دیتابیس همراه با داده‌های واقعی که از API کافه‌خودرو دریافت شده است.

هدف این پوشه: بازسازی همان سایتی که تست شده، بدون نیاز به نصب دستی. برای توسعه، منبع اصلی کد در ریشه مخزن است (`theme/lamerd-khodro` و `plugins/`)، نه این کپی.

## پیش‌نیاز

- PHP 8.2 یا بالاتر با اکستنشن `mysqli` (روی این پروژه PHP 8.5 استفاده شده).
- MariaDB/MySQL (نسخه تست: MariaDB 12.3 / MySQL 8.4).

## راه‌اندازی

```bash
# ۱) ساخت دیتابیس
mariadb -u root -e "CREATE DATABASE lamerd_khodro_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# ۲) بازگردانی داده‌ها
mariadb -u root lamerd_khodro_test < database/lamerd-khodro-test.sql

# ۳) اجرای سرور محلی از همین پوشه (اگر mysqli در php.ini فعال نیست، با -d اضافه کنید)
php -d extension=mysqli -S 127.0.0.1:8095 router.php
```

سپس `http://127.0.0.1:8095/` را باز کنید.

- سایت: `http://127.0.0.1:8095/`
- پیشخوان: `http://127.0.0.1:8095/wp-admin/`
- ورود تست: کاربر `admin` با رمز `Admin12345`

اگر پورت دیگری می‌خواهید، علاوه بر دستور بالا، `WP_HOME` و `WP_SITEURL` در `wp-config.php` و همچنین `siteurl`/`home` در جدول `wp_options` را با همان آدرس جایگزین کنید؛ در غیر این صورت وردپرس شما را به پورت ۸۰۹۵ هدایت می‌کند.

`router.php` فقط برای سرور توکار PHP است و درخواست‌های فایل‌های موجود را مستقیم برمی‌گرداند و بقیه را به `index.php` می‌دهد.

## محتوای دیتابیس

| مورد | تعداد |
|---|---|
| خودرو (`lkp_vehicles` و CPT `vehicles`) | ۱۱۵ ردیف قیمت / ۲۰ نوشته خودرو |
| قیمت و تاریخچه (`lkp_current_prices`, `lkp_price_history`) | ۱۱۵ قیمت + تاریخچه `initial` |
| نوشته‌های سایت | ۲۰ |
| ترم‌های برند | ۴ (ایران خودرو، سایپا، بهمن موتور، سایر خودروها) |
| آگهی فروش (`listing`) | ۳ نمونه (۲ فروش ویژه) |
| جدول‌ها | ۶ جدول `lkp_*` + جدول‌های استاندارد وردپرس |

داده‌های قیمت واقعی و از کافه‌خودرو هستند؛ منبع در فوتر و صفحات قیمت ذکر شده است.

## نکات امنیتی و محدودیت‌ها

- کلیدهای امنیتی، رمز کاربر `admin` و اتصال دیتابیس در این پوشه **مقادیر تستی محلی** هستند. این نصب برای اجرای روی هاست یا سایت واقعی آماده نیست؛ روی سرور واقعی باید نصب تازه انجام شود (نگاه کنید به [`docs/INSTALLATION.md`](../docs/INSTALLATION.md)).
- پوشه `.wp-test/` در ریشه پروژه همان نصب زمان توسعه است و در گیت ignore شده؛ این پوشه نسخه منتشرشده و قابل بازسازی آن است.
- تصاویر آپلودشده‌ای در دیتابیس وجود ندارد (`wp-content/uploads` خالی است)؛ پوسته بدون تصویر هم درست نمایش داده می‌شود.
- در این کپی، پوسته و افزونه‌ها به‌صورت فایل واقعی کپی شده‌اند (در نصب توسعه با symlink به ریشه مخزن وصل بودند) تا مخزن مستقل باشد.

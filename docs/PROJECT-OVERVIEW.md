# نمای کلی پروژه – لامرد خودرو

## هدف

ساخت پلتفرم جامع خودرویی با هویت مستقل «لامرد خودرو»: رسانه تخصصی اخبار، بانک اطلاعاتی خودرو، مرجع قیمت روز، نمودار تغییرات، مقایسه، شرایط فروش — با معماری آماده برای اپلیکیشن موبایل در آینده.

## اصول غیرقابل‌چشم‌پوشی

1. قالب اختصاصی، بدون هیچ صفحه‌سازی (Elementor / Divi / WPBakery ممنوع).
2. RTL واقعی در تمام اجزا + فونت وزیرمتن Local.
3. Mobile First واقعی؛ تست در 320 تا 1920 پیکسل.
4. دو افزونه مستقل: Core (ساختار) و Price Engine (قیمت)؛ منطق کسب‌وکار خارج از قالب.
5. تمام قیمت‌ها از دیتابیس داخلی نمایش داده می‌شوند؛ هیچ صفحه عمومی به API خارجی وصل نیست.
6. تاریخچه قیمت واقعی از زمان راه‌اندازی؛ بدون داده ساختگی.
7. هیچ قابلیت نمایشی به‌عنوان عملیاتی معرفی نمی‌شود؛ دکمه‌ها و فرم‌ها واقعاً کار می‌کنند.

## نقشه صفحات (Sitemap معماری اطلاعات)

```text
/                                   صفحه اصلی (۱۰ بخش قابل مدیریت)
/vehicles/                          بانک اطلاعات خودرو (فیلتر ترکیبی)
/vehicles/{slug}/                   صفحه خودرو: مشخصات فنی + قیمت + نمودار + گالری
/brands/                            فهرست برندها
/brands/{slug}/                     صفحه برند: معرفی + خودروها + قیمت + اخبار
/prices/                            قیمت روز خودرو (آمار، جدول، فیلتر، موبایل کارت)
/price/{id}/                        جزئیات قیمت خودرو + نمودار تاریخی
/compare/                           مقایسه ۲ تا ۴ خودرو
/news/                              آرشیو اخبار (دسته‌بندی استاندارد وردپرس)
/news/{slug}/                       مقاله/خبر
/price-alerts|sales category/       شرایط فروش (دسته‌بندی اخبار)
/search/?s=                         نتایج جستجوی سراسری
/wp-json/lamerd/v1/*                REST API عمومی (آماده اپلیکیشن)
```

## تصمیمات معماری کلیدی

1. **جدول قیمت مستقل از CPT:** Price Engine جداول اختصاصی (`lkp_*`) دارد و به CPT خودروها فقط «اتصال» دارد (ستون `post_id`). این باعث می‌شود قیمت حتی بدون خودروی CPT هم ذخیره و نمایش داده شود و اپلیکیشن آینده مستقل از وردپرس read کند.
2. **قرارداد سرویس بین دو افزونه:** هر دو افزونه یک تابع سراسری با نام مشخص (`lamerd_khodro_core()` / `lamerd_khodro_price_engine()`) ارائه می‌دهند و هنگام فراخوانی طرف مقابل `function_exists` بررسی می‌کنند؛ هیچ وابستگی سختی وجود ندارد.
3. **واحد پول:** API کافه خودرو «تومان» برمی‌گرداند؛ تمام ذخیره‌سازی و نمایش به تومان است.
4. **نرمال‌سازی نام خودرو:** نام‌های API (مثل «207 پانا رینگ») برای اتصال به CPT با کلید نرمال‌شده (حذف نیم‌فاصله/اعمال ی/ک عربی→فارسی) تطبیق داده می‌شوند؛ تطبیق خودکار فقط «پیشنهاد» است و تأیید نهایی با مدیر.

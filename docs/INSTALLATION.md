# نصب و راه‌اندازی – لامرد خودرو

## پیش‌نیازها

- وردپرس ≥ 6.4، MySQL/MariaDB ≥ 10.5، PHP ≥ 8.1 (تست‌شده با 8.5)
- فعال بودن `mod_rewrite` و REST API
- دسترسی cron واقعی هاست (توصیه‌شده) یا wp-cron

## مراحل

### ۱. قالب

```bash
cp -r theme/lamerd-khodro wp-content/themes/
```

پیشخوان ← نمایش ← پوسته‌ها ← فعال‌سازی «لامرد خودرو».

### ۲. افزونه‌ها

```bash
cp -r plugins/lamerd-khodro-core plugins/lamerd-khodro-price-engine wp-content/plugins/
```

پیشخوان ← افزونه‌ها ← فعال‌سازی «لامرد خودرو Core» سپس «موتور قیمت خودرو لامرد خودرو».

در فعال‌سازی Core:
- CPT خودرو، تکسونومی برند، دسته‌های اخبار (۱۲ دسته) ایجاد می‌شوند.
- منوهای ناوبری پیش‌فرض (در صورت خالی بودن) با صفحات پیش‌نهادی.

در فعال‌سازی Price Engine:
- جداول `lkp_*` با `dbDelta` ساخته می‌شوند (بررسی نسخه در هر بار به‌روزرسانی افزونه).
- منبع «کافه خودرو» در `lkp_price_sources` ثبت می‌شود.
- رویداد WP-Cron با فاصله پیش‌فرض ۶۰ دقیقه برنامه‌ریزی می‌شود.

### ۳. ساخت صفحات

پیشخوان ← برگه‌ها ← افزودن برگه، و برای هر برگه «قالب برگه» را انتخاب کنید:

| برگه (پیشنهادی) | قالب |
|---|---|
| قیمت روز خودرو | قیمت روز خودرو |
| مقایسه خودرو | مقایسه خودرو |
| بانک اطلاعات خودرو | بانک اطلاعات خودرو |
| درباره ما / تماس با ما | برگه پیش‌فرض |

سپس در «تنظیمات ← خوانایی» برگه اصلی را به «صفحه نخست» (صفحه اصلی سفارشی) تنظیم کنید.

صفحه جزئیات قیمت (`/price/{id}/`) نیاز به برگه ندارد: Price Engine قانون rewrite ثبت می‌کند (Settings ← Permalinks ← ذخیره مجدد در صورت نیاز).

### ۴. منوها

نمایش ← منوها: منوی «اصلی» و در صورت نیاز «موبایل» و منوهای فوتر را بسازید.
(در غیر این صورت، قالب فهرست صفحات را به‌صورت خودکار نمایش می‌دهد.)

### ۵. اولین همگام‌سازی قیمت

پیشخوان ← مدیریت قیمت خودرو ← همگام‌سازی ← **دریافت دستی**.

- پس از موفقیت: تعداد خودروها/تغییرات در داشبورد دیده می‌شود.
- چک: صفحه «قیمت روز خودرو» باید جدول را از دیتابیس داخلی پر کند.

### ۶. Cron واقعی هاست (توصیه‌شده)

wp-cron در بازدیدهای کم فعال نمی‌شود. در هاست، یک Cron واقعی بسازید:

```cron
*/30 * * * * /usr/bin/php /home/USER/public_html/wp-cron.php > /dev/null 2>&1
```

یا با WP-CLI:

```cron
*/30 * * * * cd /home/USER/public_html && wp cron event run --due-now --quiet >> /dev/null 2>&1
```

(بازه را با «تنظیمات ← sync_interval» هماهنگ کنید؛ پیش‌فرض ۶۰ دقیقه است.)

### ۷. تنظیمات پیشنهادی

- «تنظیمات»: فاصله همگام‌سازی = ۶۰ دقیقه؛ Snapshot روزانه = فعال.
- «صفحه اصلی» (در پیشخوان Core): متن‌ها، تعداد هر بخش، بنرها.
- «تنظیمات ← خوانایی»: ساختار پیوند یکتا = «نام نوشته».

## به‌روزرسانی

1. جایگزینی پوشه قالب/افزونه (بدون حذف `wp-config.php`).
2. بازدید از پیشخوان → در صورت تغییر اسکیما، `dbDelta` خودکار اجرا می‌شود.
3. بررسی لاگ «همگام‌سازی» پس از اولین اجرا.

## حذف

- غیرفعال‌سازی عادی: **داده‌ها حفظ می‌شوند**.
- حذف کامل داده‌ها: پیشخوان ← مدیریت قیمت ← تنظیمات ← «حذف کامل داده‌ها» (دو تأیید) سپس حذف افزونه.

## عیب‌یابی

| مشکل | بررسی |
|---|---|
| جدول خالی است | لاگ همگام‌سازی؛ خطای 429/شبکه؛ فعال بودن منبع |
| نمودار داده ندارد | طبیعی در آغاز؛ داده از زمان اولین دریافت جمع می‌شود |
| خطای REST | Settings ← Permalinks ← ذخیره؛ فعال بودن `mod_rewrite` |
| فونت لود نمی‌شود | مسیر `assets/fonts/` و دسترسی خواندن |
| دو اجرا هم‌زمان | قفل `lkp_sync_lock` پس از ۱۰ دقیقه منقضی می‌شود؛ در داشبورد وضعیت دیده می‌شود |

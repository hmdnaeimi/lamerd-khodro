# طراحی واکنش‌گرا و Mobile First

## ۱. استراتژی

طراحی از کوچک‌ترین نمایشگر شروع می‌شود و با `min-width` گسترش می‌یابد (نه `max-width` معکوس):

```css
/* Mobile base (320px) → سپس: */
@media (min-width: 480px)  /* موبایل بزرگ */
@media (min-width: 768px)  /* تبلت عمودی */
@media (min-width: 1024px) /* تبلت افقی/لپ‌تاپ کوچک */
@media (min-width: 1366px) /* لپ‌تاپ */
@media (min-width: 1920px) /* دسکتاپ بزرگ – محدودیت عرض محتوا 1320px */
```

## ۲. نکات اجرایی

- **بدون اسکرول افقی:** `overflow-x: hidden` روی `body` + کنترل المان‌های عریض (جدول، iframe، اسلایدر) با `max-width: 100%` + بازبینی با `document.documentElement.scrollWidth` در تست.
- **سیستم گرید:** Flexbox/Grid با `gap`؛ بدون float.
- **Touch targets:** حداقل ۴۴×۴۴ پیکسل برای دکمه‌ها و لینک‌های ناوبری موبایل.
- **منوی موبایل:** کشویی تمام‌صفحه از راست، با `aria-expanded`، قفل اسکرول هنگام باز بودن، بسته شدن با Escape.
- **فرم‌ها:** `inputmode` مناسب (numeric برای قیمت)، فونت ≥۱۶px جلوگیری از زوم خودکار iOS، لیبل واقعی.
- **تصاویر:** `srcset`/`sizes`، `loading="lazy"`، `aspect-ratio` جلوگیری از CLS.
- **جدول قیمت:** دسکتاپ = جدول کامل؛ موبایل (<768px) = **کارت اختصاصی** (جدول مخفی می‌شود، نه کوچک‌شده).

### اولویت اطلاعات در کارت موبایل قیمت

1. نام خودرو + برند
2. قیمت بازار (بزرگ‌ترین عدد)
3. تغییر قیمت (ریال + درصد با رنگ)
4. ⌄ جزئیات بازشونده: قیمت کارخانه، اختلاف، وضعیت تولید، زمان به‌روزرسانی، لینک جزئیات

## ۳. جدول مقایسه در موبایل

- افق‌کش (overflow-x) با ستون چسبان `position: sticky; right: 0` برای برچسب ردیف‌ها.
- در <480px: نمایش ردیفی «مشخصات هر خودرو به ترتیب» با سلکتور خودرو (شبیه tab) به‌جای جدول عریض.

## ۴. چک‌لیست تست ابعاد

| عرض | چک |
|---|---|
| 320 | بدون اسکرول افقی؛ هدر جمع‌شده؛ کارت‌ها تک‌ستونه |
| 360/375/390 | رایج‌ترین موبایل‌ها؛ لمسی بودن دکمه‌ها |
| 430 | موبایل بزرگ؛ دو ستونه شدن کارت‌ها در صورت جا |
| 768 | شروع جدول دسکتاپ یا کارت+جدول واسط |
| 1024 | منوی کامل؛ چیدمان دوستونه |
| 1366/1920 | چیدمان حداکثری با محدودیت 1320px |

صفحات برای تست: اصلی، قیمت روز، جزئیات قیمت (نمودار)، خودرو، مقایسه، اخبار، مقاله، جستجو، ۴۰۴.

## ۵. نمودار در موبایل

- Canvas با ارتفاع ثابت ۲۶۰px (دسکتاپ ۳۸۰px).
- Tooltip تاچ‌فعال؛ کنترل بازه‌ها به‌صورت چیپ‌های اسکرول‌شونده افقی.
- Legend زیر نمودار (نه روی آن) تا فضای موبایل حفظ شود.

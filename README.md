# لامرد خودرو – Lamerd Khodro

پلتفرم تخصصی خودرو: رسانه اخبار، بانک اطلاعاتی خودرو، مرجع قیمت روز، نمودار تغییرات قیمت، مقایسه خودرو، شرایط فروش و آگهی‌های فروش خودرو.

- دامنه: https://lamerdkhodro.ir
- زبان: فارسی | جهت: RTL (`dir="rtl"` / `lang="fa-IR"`)
- سکو: وردپرس + MySQL | قالب اختصاصی بدون صفحه‌ساز
- فونت: Vazirmatn (وزیرمتن) — به‌صورت Local، بدون وابستگی به Google Fonts

## اجزای پروژه

| جزء | مسیر | نقش |
|---|---|---|
| قالب اختصاصی | `theme/lamerd-khodro/` | رابط کاربری، صفحات، RTL، Mobile First |
| افزونه هسته | `plugins/lamerd-khodro-core/` | بانک اطلاعات خودرو (CPT، برند، مشخصات فنی، جستجو، تنظیمات صفحه اصلی) + آگهی‌های فروش خودرو |
| موتور قیمت | `plugins/lamerd-khodro-price-engine/` | دریافت از API کافه خودرو، ذخیره دائمی، تاریخچه، نمودار، گزارش، خروجی |
| مستندات | `docs/` | معماری، دیتابیس، API، امنیت، سئو، نصب، تغییرات |

منبع قیمت: [کافه خودرو](https://cofekhodro.ir) — استفاده از داده‌ها تنها با ذکر منبع مجاز است (محدودیت ۱۲۰ درخواست در دقیقه برای هر IP).

## نصب

مراحل کامل نصب در [docs/INSTALLATION.md](docs/INSTALLATION.md) آمده است. خلاصه:

1. قالب `theme/lamerd-khodro` را در `wp-content/themes/` کپی و فعال کنید.
2. افزونه‌های `lamerd-khodro-core` و `lamerd-khodro-price-engine` را در `wp-content/plugins/` کپی و فعال کنید.
3. از «مدیریت قیمت خودرو ← همگام‌سازی» اولین دریافت را اجرا کنید.
4. صفحات «قیمت روز خودرو»، «مقایسه» و «خودروها» را با قالب‌های اختصاصی بسازید (جزئیات در INSTALLATION).

## وضعیت توسعه

پیاده‌سازی نسخه ۱.۰.۳ کامل شده است: ۴۹ فایل PHP (قالب ۲۳، هسته ۱۲، موتور قیمت ۱۴) به‌همراه CSS/JS و فونت محلی. جزئیات و نتیجه تست‌ها در [docs/CHANGELOG.md](docs/CHANGELOG.md).

### چه چیزی واقعاً کار می‌کند

- CPT خودرو + برند + ۷ گروه مشخصات فنی؛ جستجوی زنده و REST `lkc/v1`.
- دریافت، اعتبارسنجی و ذخیره دائمی قیمت در ۶ جدول `lkp_*`؛ تاریخچه فقط روی تغییر واقعی؛ نمودار SVG؛ ۱۲ گزارش؛ خروجی CSV/XLSX/PDF.
- صفحات عمومی مستقل از API: نمایش از دیتابیس داخلی، با برچسب کهنگی داده و ذکر منبع.
- آگهی‌های فروش خودرو (فقط درج توسط مدیر، بدون سبد خرید و پرداخت): CPT اختصاصی، قیمت و مشخصات، «فروش ویژه» با تاریخ پایان و تایمر شمارش معکوس، بخش مدرن صفحه اصلی، آرشیو و صفحه تک‌آگهی.

### تأییدهای انجام‌شده

| بررسی | نتیجه |
|---|---|
| `php -l` روی هر ۴۹ فایل PHP | بدون خطا |
| تست دودی (بارگذاری، فعال‌سازی، ۱۲ گزارش، اعتبارسنج، نمودار، تاریخ شمسی) | ۳۶/۳۶ موفق |
| تلاش زنده Provider + Validator روی API کافه خودرو | ۱۱۵ خودرو، ۱۶ قیمت `null` حفظ‌شده، ۰ خطای اعتبارسنجی |
| نصب واقعی وردپرس ۷.۱.۴ + MySQL 8.4 (`.wp-test/`) | نصب، فعال‌سازی قالب و هر دو افزونه، ساخت هر ۶ جدول `lkp_*` با `dbDelta` |
| اولین همگام‌سازی از داخل وردپرس | ۱۱۵ خودرو، ۱۱۵ قیمت، ۱۱۵ تاریخچه `initial`، ۰ خطا |
| صفحات عمومی: خانه، آرشیو خودرو، خودرو، برند، مقایسه، جستجو، ۴۰۴ | همه کد درست (۲۰۰/۴۰۴) و بدون خطای PHP |
| ۸ صفحه پیشخوان «مدیریت قیمت خودرو» + فهرست CPT | همه ۲۰۰ و بدون خطای PHP |
| نمایش قیمت `null` | «ناموجود» (نه صفر) در باکس قیمت و کارت‌ها |
| شمارنده بازدید خودرو | یک‌بار در هر نشست؛ تکرار بازدید مقدار را بالا نمی‌برد |
| بخش آگهی‌ها در خانه/آرشیو/تک‌آگهی | همه ۲۰۰؛ ۳ آگهی نمونه، ۲ نشان «فروش ویژه» |
| تایمر فروش ویژه | شمارش ثانیه‌ای زنده؛ پس از تاریخ پایان، نشان و تایمر حذف و آگهی عادی می‌شود |
| پیشخوان آگهی‌ها | فهرست، فرم افزودن با دو متاباکس، تنظیمات بخش صفحه اصلی: همه ۲۰۰ بدون خطا |

### آنچه هنوز تأیید نشده

- نمودار قیمت با چند روز داده واقعی: در نصب تست فقط یک نقطه `initial` وجود دارد، پس روند چندروزه هنوز دیده نشده است.
- Lighthouse و Core Web Vitals پس از استقرار روی هاست.
- در نصب تست از ۲۰ خودروی نمونه، ۴ ترم برند ساخته شد (ایران خودرو، سایپا، بهمن موتور، سایر خودروها)؛ برچسب برند از فیلد `brand_group` منبع می‌آید و برای خودروهای گروه‌های بدون نمونه (مدیران خودرو، کرمان موتور) ترمی ساخته نشده است.
- مشخصات فنی نمونه‌ها خالی است (منبع API فقط نام، برند و قیمت می‌دهد)، پس بخش «مشخصات فنی» در این نصب نمایش داده نمی‌شود؛ پس از پر کردن فیلدها در ویرایش خودرو، بخش و جدول مقایسه خودکار پر می‌شوند (تست رندر انجام شد).
- آگهی‌های نمونه فقط قیمت بازار واقعی و برند/شهر دارند؛ فیلدهای سال، کارکرد، رنگ و شماره تماس خالی‌اند تا عدد ساختگی درج نشود. با پر کردن آن‌ها در پیشخوان، چیپ‌های کارت و دکمه تماس کامل می‌شوند.
- آگهی‌ها فقط از پیشخوان ثبت می‌شوند؛ فرم ارسال آگهی توسط کاربر و پرداخت/نمایش ویژه پولی وجود ندارد (طبق خواسته پروژه).
- از سمت این دستگاه، API کافه خودرو فقط با IPv4 پاسخ داد؛ اگر هاست IPv6 ترجیح بدهد ممکن است دریافت کند شود (Retry پوشش می‌دهد).
